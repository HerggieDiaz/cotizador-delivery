## ⚡ Características Principales

* 🏛️ **Tasa BCV en Tiempo Real:** Actualización automática desde API oficial para conversión exacta a Bolívares.
* 🌙 **Detección Nocturna Automática:** Aplica el recargo nocturno automático entre 9:00 PM y 6:00 AM.
* 📦 **Multiplicadores de Carga:** Opciones para envíos estándar, carga pesada/voluminosa (+25%) u objetos frágiles (+15%).
* 🗺️ **Acceso Directo a Google Maps:** Apertura limpia e inmediata para verificar rutas en tiempo real.
* 💬 **Integración Nativa con WhatsApp:** Genera un mensaje listo con el desglose del servicio para enviar al cliente en un toque.
* 🔄 **Botón "Nueva Cotización":** Reinicia todos los campos al instante para agilizar el trabajo diario.
